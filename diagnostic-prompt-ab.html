실사용 DB 샘플 비교

본앱(Couple)의 서버 저장 실제 번역을 읽기 전용으로 가져옵니다. 저장 당시 번역/역번역은 기준값으로만 로그에 남기고, 같은 원문을 P160A 기준·현재 P161A·후보 P167A로 각각 1회 재번역·재역번역합니다. DB 결과는 아래 전용 로그 영역에만 쌓이며 전용 복사/저장 버튼으로 내보냅니다. 진단 결과는 실사용 DB에 다시 저장하지 않습니다. 양방향은 가능한 범위에서 K→L/L→K를 균형 표집하며, 실패 기록·재번역 시도·중복 원문은 제외합니다.

고정/holdout 결과 로그
